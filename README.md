# strange-attractors
A C++ simulator for chaos attractors

## Description
strange-attractors is a Vulcan based simulator for modeling chaos attractors in 3D space. These attractors are governed by a set of differential equations that are deterministic. Despite this, it is impossible to predict the movements of particles under the influence of chaos attractors over the long term and thats what earns them their names. The simulator current supports all of the following strange attractors:
### Attractors
1. The Lorenz Attractor
2. The Rössler Attractor
3. The Aizawa Attractor
4. The Halvorson Attractor
5. Thomas' Cyclically Cymmetric Attractor
6. The Chen-Lee Attractor
7. The Arneodo Attractor
8. The Sprott B Attractor
9. The Dadras Attractor
10. The Rabinovich-Fabrikant Attractor
